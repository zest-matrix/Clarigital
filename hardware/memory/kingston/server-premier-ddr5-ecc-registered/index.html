Kingston Server Premier DDR5 ECC Registered DIMM: The Complete Guide

Kingston’s server-class DDR5 registered memory, announced in January 2023 at 4800MT/s and now listed at 4800, 5600 and 6400MT/s. Simple to deep dive, every number links to its source.

1.At a glance

SimpleStart here

Server Premier DDR5 ECC Registered DIMM is Kingston’s registered memory for servers. In January 2023 Kingston announced 16GB, 32GB and 64GB modules at 4800MT/s, validated on the 4th Gen Intel Xeon Scalable Processor 1. Kingston’s site now has pages for 4800, 5600 and 6400MT/s 234.

Deep diveThe technical detail

The announcement exists in three versions: “Fountain Valley, CA– January 23, 2023”, “Sunbury-on-Thames, UK – 23 January, 2023” and “Taipei – February 15, 2023” 156. All give the same four 4800MT/s part numbers 156. The current pages list capacities from 16GB to 128GB 34. Kingston dates none of the later speed and capacity additions 14.

2.Launch and lineup

SimpleStart here

Kingston framed the launch around Intel’s 4th Gen Xeon, which it said was “first to support next-generation DDR5 server-class memory” 156.

Deep diveThe technical detail

The Fountain Valley version quotes Mike Mohney, Sr Technology Manager DRAM, the Sunbury-on-Thames version quotes Iwona Zalewska, DRAM business manager, Kingston, EMEA, and the Taipei version attributes its quote to Kingston without a name 156. All three versions carry the same headline, beginning “Kingston Technology Server Premier DDR5 4800MT/s” 156. None of the three versions says why the others exist 156.

3.What’s inside the module

SimpleStart here

The release describes dual independent 32-bit subchannels, 40-bit for ECC, and on-die ECC 156.

Deep diveThe technical detail

The releases say the modules include “on-die ECC (ODECC)” and “dual independent 32-bit subchannels (40-bit for ECC)” 156. They also say at 4800MT/s each module provides a peak bandwidth of 38.4GB/s 156. The sources checked for this guide give no module dimensions or heat spreader description 13.

6.What it’s compatible with

SimpleStart here

The 2023 release says the 4800MT/s modules were validated on the 4th Gen Intel Xeon Scalable Processor, and names no AMD processor. Kingston’s Server Premier hub now says the line is platform validated with Intel and AMD 17.

Deep diveThe technical detail

The releases say the 64GB, 32GB and 16GB modules “have been validated on the 4th Gen Intel® Xeon® Scalable Processor” 1, and none of the three versions mentions AMD 156. The hub says Server Premier is “platform validated with Intel and AMD” 7. Kingston does not date the wider wording, and the 4800, 5600 and 6400MT/s pages themselves, as read for this guide, carry no validation wording 234.

7.Official pricing

SimpleStart here

None of Kingston’s sources checked states a price 13.

Deep diveThe technical detail

The releases and pages list no price or recommended price; the part tables have Buy links 15634.

8.Rated vs. real-world speed

SimpleStart here

Kingston states a 38.4GB/s peak bandwidth per module at 4800MT/s and publishes no benchmarks. The releases list a limited lifetime warranty 156.

Deep diveThe technical detail

The releases say “At 4800MT/s, each DDR5 Registered DIMM provides a peak bandwidth of 38.4GB/s” 156. The releases list “Limited Lifetime warranty” as a feature 156. Kingston’s warranty statement covers listed products “for the product lifetime” and lists Server Premier among its memory modules 8.

9.Where this family sits in the lineup

SimpleStart here

Kingston’s Server Premier hub lists the 5600MT/s and 6400MT/s RDIMM pages but not the 4800MT/s page 72.

Deep diveThe technical detail

The hub lists DDR5 5600MT/s ECC Registered DIMM and DDR5 6400MT/s ECC Registered DIMM among its four DDR5 lines 7. A separate 4800MT/s ECC Registered DIMM page exists 2, with a plain asterisk after the speed rather than the unrendered template tag on the other two 234.

10.Hidden in plain sight

SimpleStart here

Kingston’s three RDIMM part tables each have different columns, and none of the four part numbers in the 2023 release appears on the current 4800MT/s page 12.

Deep diveThe technical detail

The 4800MT/s table lists Part Number, Capacity, Chip Organization, Ranking, DRAM MFR, Die Revision, Specs and PCN 2. The 5600MT/s table adds DRAM Density and Component Control, with “DRAM Lock” or “Full Lock” per part 3. The 6400MT/s table has DRAM Density but no Component Control column 4. Kingston gives no reason for the differences 234. The 2023 release lists KSM48R40BD4TMM-64HMR, KSM48R40BS4TMM-32HMR, KSM48R40BD8KMM-32HMR and KSM48R40BS8KMM-16HMR 1; the current 4800MT/s page lists KSM48R40BS8-16HA, KSM48R40BS8-16MD, KSM48R40BD8-32HA, KSM48R40BD8-32MD, KSM48R40BD4-64HA and KSM48R40BD4-64MD instead 2. This guide does not decode the part-number suffixes.
